# SJTU Furry 活动组织手记

## 引言

这份手记由瑞皮 rappy 编写，记录自 2023 年起参与 SJTU Furry 社群、组织与策划活动的经历和思考。希望在毕业离校前，把这些经验留给后来愿意带着大家玩起来的人，让组织活动的热情和经验继续传下去。

手册分为**立志篇、活动篇、工具篇**：从组织者的心态与担当，到具体活动的筹备和执行，再到常用工具与技巧。目前正在逐步编写，部分章节已有正文，其余章节先保留框架。下面的介绍说明每篇计划讨论的内容，不代表所有章节都已写完。

## 从这里开始

- [序言](intro/introduction.md)：为什么写这份手记，希望为社群和后来的组织者留下什么。
- [完整目录](SUMMARY.md)：按篇章查找全部文章。

## 立志篇

关于为什么开始、如何迈出第一步，以及组织者需要面对的责任与选择。既记录个人成长的经历，也讨论管理中的价值判断、处理问题的心态和与人合作的方法。

- [引言——立志篇](determination/opening.md)：为什么要分享组织者的成长经历，以及怎样阅读这一篇章。
- [从零开始做一个“领导者”](determination/kickstarter.md)：从普通群友到主动组织活动的经历、转折与体会。
- [举办活动的目的和修养](determination/activity_purpose.md)：先想清楚为什么办活动、希望带来什么，再讨论组织者的基本修养。
- [行动力是关键](determination/action_is_key.md)：怎样把想法变成第一步，跟进承诺，并在遇到困难时调整安排。
- [群主的道德修养](determination/ethics.md)：哪些价值值得优先守护，如何避免意气用事，以及管理者应有的担当。
- [世界上神人不少，别太敏感。](determination/difficult-people.md)：遇到棘手行为时怎样依据群规处理，接受无法万全的现实，也保护好自己的心态。
- [适当分工合作](determination/teamwork.md)：一个人做不完时如何求助、交代任务、协调进度，并有礼貌地对待协作者。

## 活动篇

记录为什么要办、怎样筹备、现场遇到了什么，以及下次可以如何调整。具体经验按**活动形式**分类，每种形式都按“引言、活动的起源、办的流程（一些经验）、历史举办的情况”展开；每年的惯例活动另设一篇，方便安排一个学年的活动节奏。

- [引言——活动篇](activities/opening.md)：如何按活动形式查找经验，以及具体流程和年度惯例之间的关系。
- [每年惯例活动](activities/annual-traditions.md)：一个学年中通常会举办哪些活动、怎样安排时间，以及历年的延续与变化。
- [轰趴](activities/house-party.md)：从人数、预算、场地和报名，到现场节奏、临时变动与收尾结算。
- [饭局](activities/dinners.md)：迎新饭与日常聚餐怎样选店、订位、通知、安排交流并处理费用。
- [全家福约稿](activities/group-portrait.md)：怎样收集角色设定与互动需求，对接画师、确认草稿、跟进修改和交付。
- [组织共同前往兽展](activities/convention-trips.md)：共同出行的责任边界，以及行程、交通住宿、集合与现场联系的协调。
- [交换礼物](activities/gift-exchange.md)：礼物范围、报名与交换规则、现场流程，以及迟到、缺席等情况的处理。

### 惯例上的年度安排

- **9月底：新生饭**
- **10月国庆结束前：秋日小聚**
- **12月圣诞节：交换礼物圣诞爬**
- **2月/3月开学：新生饭**
- **五一/清明/儿童节：春日小聚**

时间为常见安排，具体日期与活动形式由当年的情况决定；历年记录与安排经验集中在“每年惯例活动”一篇。

- [群组管理：QQ 公告发布](tools/group-management.md)：公告内容的准备、发布、提醒、更新，以及与群规和管理员交接的衔接。
