# SJTU Furry 活动组织手记

这是一份面向 SJTU Furry 社群活动组织者的经验手册，由瑞皮编写，记录自 2023 年起组织与策划活动的经历和思考。

手册分为**立志篇、活动篇、工具篇**，分别介绍组织者的心态、具体活动的组织经验，以及常用工具与技巧，目前正在逐步编写。

## 可以怎么读

这份手记里面，其实有两种不太一样的事情。

一种是你自己想玩，也想约大家一起玩。比如约一次饭、去唱 K、玩桌游，或者线上约个游戏。把时间地点说清楚，确认一下安排，带大家玩完这一次，就已经很好了。不需要因为组织了一次活动，就变成要负责群里所有事情的人。

另一种是想长期组织群里的主要活动，或者参与社群的管理。除了活动本身，还要考虑群里的规则、人与人之间的关系，以及以后怎么把这些事情继续做下去。这部分要考虑的东西会多一些。

**如果你只是想约大家一起玩，暂时不想管群里的事情，可以直接看[活动篇](#活动篇)，需要用到什么再去[工具篇](#工具篇)找。** 立志篇更多是我的经历和想法，可以当故事看，不看也不影响你办活动。

如果你想长期负责一些活动，或者参与群里的管理，可以再看看[立志篇](#立志篇)里面关于分工、责任和处理问题的内容。不过这些也不是标准答案，只是把我自己经历过的事情写下来，给大家参考一下。

## 从这里开始

- **第一次来**：先读[序](intro/introduction.md)，了解作者与这份手记的由来，再按需要选择篇章。
- **想快速找某一篇**：查看[完整目录](SUMMARY.md)。

## 立志篇

从个人经历出发，讨论迈出第一步、承担责任、处理问题与分工合作。适合想了解组织者心态与成长过程的读者。

- [写在前面](determination/opening.md)：这一篇章的内容与阅读建议。
- [从零开始做一个“组织者”](determination/kickstarter.md)：从普通群友到主动组织活动的经历、转折与体会。
- [适当分工合作](determination/teamwork.md)：求助、任务交接、进度协调，以及对协作者的尊重。
- [群主的道德修养](determination/ethics.md)：价值排序、避免意气用事，以及管理者的责任与担当。
- [世界上神人不少，别太敏感。](determination/difficult-people.md)：依据群规处理棘手行为，接受无法万全的现实，照顾自己的心态。

## 活动篇

按**活动形式**查找组织经验，每种形式记录“活动的起源、办的流程与经验、历史举办情况”。要决定这一年什么时候办什么活动，可以先看[每年惯例活动](activities/annual-traditions.md)。

- [写在前面](activities/opening.md)：活动篇的读法，以及活动形式与年度惯例的关系。
- [办一次活动，先想清楚什么](activities/planning-basics.md)：为什么办、玩什么、怎么办，以及人数、报名、公告和纪念物料的安排。
- [日常团建](activities/ordinary-activity.md)：KTV、桌游、泡汤等容易约起来的文娱休闲活动，以及约人、预订与费用协调。
- [线上团建：一起约游戏](activities/online-gaming.md)：游戏选择、约人开局、人数安排、新人参与与线上交流。
- [饭局](activities/dinners.md)：选店、订位、通知、交流安排与费用处理。
- [每年惯例活动](activities/annual-traditions.md)：年度活动节点、时间安排与历年变化。
- [轰趴](activities/house-party.md)：人数、预算、场地、报名、现场节奏与收尾结算。
- [全家福约稿](activities/group-portrait.md)：设定收集、画师对接、草稿确认、修改与交付。
- [组织共同前往兽展](activities/convention-trips.md)：出行分工、行程与住宿协调、集合及现场联系。
- [交换礼物](activities/gift-exchange.md)：礼物范围、报名与交换规则、现场流程，以及迟到、缺席等情况的处理。

## 工具篇

按正在做的事情查找工具与技巧：收集信息、同步安排、设计、剪辑、写通知、发布公告或维护社群资源。可按需参考，无需从头读完。

- [写在前面](tools/opening.md)：工具篇的范围，以及按需要选择工具的方法。
- [文案编写：把事情说清楚，也用好 AI](tools/copywriting.md)：功能性通知的必需信息，以及 AI 辅助整理、改写与校对。
- [腾讯文档：收集表与备忘录](tools/tencent-docs.md)：收集表编辑、结果整理，以及备忘录的时间线、分工与变更记录。
- [用 Canva 进行设计](tools/canva.md)：活动海报的需求、尺寸、素材、信息层级、协作修改和导出检查。
- [剪映简略介绍](tools/jianying.md)：从素材整理到基本剪辑、字幕声音、封面导出与发布前确认。
- [群组管理：QQ 公告发布](tools/group-management.md)：公告准备、发布、提醒、更新与管理员交接。
- [社群资源：B 站与社群网页](tools/community-resources.md)：内容入口、发布维护与账号交接。
