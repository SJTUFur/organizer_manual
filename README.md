# SJTU Furry 活动组织手记

这份手记由瑞皮 rappy 编写，记录自 2023 年起参与 SJTU Furry 社群、组织与策划活动的经历和思考。希望在毕业离校前，把这些经验留给后来愿意带着大家玩起来的人，让组织活动的热情和经验继续传下去。

手册计划分为**立志篇、活动篇、工具篇**：从组织者的心态与担当，到具体活动的筹备和执行，再到常用工具与技巧。目前正在逐步编写，尚未完成的章节保留框架，工具篇将在后续补充。
