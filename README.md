## 参与编写

可以直接编辑对应 Markdown 文件，也可以通过 Issue 提出建议、通过 Pull Request 补充经验。记录时请说明背景、自己的选择、实际结果与下一次的调整。新增章节时同步更新 SUMMARY.md 中的目录链接。

本仓库采用 GitBook 可导入的 Markdown 手册结构。连接 GitBook 后可作为在线手册阅读；GitHub 中也可直接点击目录阅读。
